# 思旋 · A股 v5.1 量化站

自动化的中期反转（v5.1）选股站点。**两条路保证数据是最新的**：

1. **页面自己扫（默认，零依赖）** —— 打开页面，浏览器直接跑全市场扫描，约 5 秒出今日榜单
2. **GitHub Actions 每天跑（推荐）** —— 每个交易日 16:30 自动扫描并更新 `docs/data.json` + `docs/archive.json`

> 实测：浏览器内扫描与 Python 扫描器**前 12 名逐项完全一致**（代码、ret60、20 日均额全对得上）。

## 一、策略（v5.1，别改参数）

| 项 | 值 |
|---|---|
| 选股 | 沪深主板（60/000/001/002/003）+ 收盘价 20~40 元 + 20 日均额 ≥ 5000 万 |
| 排序 | **ret60（60 日涨跌幅）升序取前 3**（跌得最惨的就是最强的，实测加任何过滤都有害） |
| 买点 | 次日**开盘价 × 0.995 限价单**，不成交即撤销，不递补不追高 |
| 持有 | **12 个交易日**（只计开市日） |
| 止损 | **−15%** |
| 止盈 | 不设固定止盈；涨到 **+15%** 启动移动止盈，之后从**最高收盘价回撤 10%** 出场 |
| 频率 | **非重叠采样**：每 12 个交易日一批，一年约 20 批。绝大多数日子「无新信号」是正常状态 |

## 二、部署（GitHub Pages，30 秒）

1. 在 GitHub 上新建空仓库（public），把本目录**所有文件**传上去（`data/k180_cache.json` 已忽略，不必传）
2. Settings → Pages → Source 选 `Deploy from a branch` → Branch `main` / 目录 `/docs` → Save
3. Actions 页 → 「每日收盘后更新（v5.1）」→ Run workflow（手动跑第一次）
4. 打开 `https://<用户名>.github.io/<仓库名>/` → 站点里填一下仓库名 `用户名/仓库名`（用于联网拉最新数据）

之后**每天 16:30（北京时间）Actions 自动跑**：交易日自检 → 刷新榜单 → 重算历史 → 重建站点 → 更新日历存档。
**周末和节假日自动跳过**，不产生提交。

## 三、目录

```
docs/index.html      站点（GitHub Pages 就服务这个）
docs/data.json       当天榜单（页面联网拉它，永远最新）
docs/archive.json    日历存档（Actions 每天追加，换设备也能恢复）
思旋_量化站_模板.html  源码模板（data 用占位符，构建时内联）
build_site.py        把数据内联进模板 → 生成 docs/index.html + 自包含单文件
refresh_pool.py      刷新当日榜单（与浏览器内扫描同源同口径）
history_v51.py       历史回算：过去每一天的榜单 + 每批真实战绩
archive_day.py       生成 / 增量更新 docs/archive.json
daily_update.py      每日入口（交易日自检 + 上面几步，给 Actions 用）
gen_universe.py      重建 data/universe.txt（新股上市后跑一次）
publish_csb.py       顺手发一个 CodeSandbox 临时公网链接（可选）
```

## 四、口径一致性（重要）

浏览器内扫描、`refresh_pool.py`、`history_v51.py` **三处必须用同一套算法**，否则网页和回测会打架：

- 快照 `qt.gtimg.cn/q=...`（GBK）
- 日 K `ifzq.gtimg.cn/appstock/app/kline/kline?param=CODE,day,,,N`（**不复权**）
- `ret60 = close[-1]/close[-61] - 1`（最后 61 根收盘，不是首根）
- `amt20 = mean(close × vol)` 最近 20 根；腾讯 vol 单位是**手**，×100 才是股
- 过滤用的价格 / 成交额一律取**当天**的值，不用今天的

## 五、诚实局限

- 历史回算目前只有 **9 个独立信号日**，是小样本，统计显著 ≠ 未来有效
- 20~40 元带的收益近期已明显衰减（第 1~5 批多数亏损，第 6~7 批才大幅盈利）
- 本金约 1.08 万太小，**跑满 5 批再评估**，单批结果不做结论
- 未考虑涨跌停无法成交、停牌等极端情况
- 数据不复权，遇除权会导致 ret60 失真（这是既定口径，与云盘回测一致）
